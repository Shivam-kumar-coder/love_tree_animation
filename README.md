# Love Tree Animation

A romantic interactive web page featuring:
- animated glowing heart effects
- a blooming tree created with canvas drawing
- floating particles and touch effects
- a typewriter-style love message
- background music support

## Features
- Full-screen animated romantic scene
- Responsive design for desktop and mobile
- Elegant handwritten style for the message
- Click-to-start experience
- Touch interaction with floating hearts

## Files
- `index.html` — complete website structure, styling, and animation logic

## How to Use
1. Download or clone this project.
2. Place your background music file as `music.mp3` in the same folder.
3. Open `index.html` in a browser.
4. Tap/click the screen to start the animation.

## Demo
Open the page in a browser and enjoy the romantic animation.

## Customization
You can edit:
- the message text in the JavaScript section
- colors and glow values in the CSS
- the music file name in the `<audio>` tag
- the animation speed and branch size in the script

## Technologies Used
- HTML
- CSS
- JavaScript
- Canvas API
